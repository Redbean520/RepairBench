# Repair Bench（修补台）

RimWorld 1.7 mod —— 用命令标记把磨损的武器 / 衣物 / 护甲送到修补台，消耗通用「修补剂」修回 100% 耐久。

- packageId：`redbean.repairbench`
- modVersion：0.1.0
- 支持版本：RimWorld 1.7
- 作者：Redbean

## 玩法

1. 研究「修补技术」（Medieval 时代，600 点，前置「锻造」）解锁修补台与标记。
2. 造一张**修补台**（3×1，钢材 75 + 布料 15），在旁边用「制作修补剂」配方做**修补剂**
   （钢材 10 + 布料 5 → 5 个；可在燃料锻造台 / 电力锻造台制作）。
3. 把修补剂搬到修补台上（和原版给燃料锻造台加燃料一样），一台最多装 20 个。
4. 给要修的东西挂上**修补标记**，三种方式：
   - 「命令」菜单点「修补」，点击或**按住左键拖出矩形框选**地上磨损的武器 / 衣物 / 护甲（同原版标记的拖拽手感）；
   - 或者**选中一个小人后，右键直接点地上那件装备**，选「维修装备」（会显示需要多少修补剂）；
   - 想要**立刻派人去修**（不进工作队列扫描、像原版「优先执行工作」）：
     右键那件装备选「**强制维修**」；也可以**右键一座修补台**，菜单会列出全图所有带标记的装备，
     逐个给「强制维修：<装备名>」，优先用你点的那座台（台里修补剂不够会变灰并说明原因）；
   - 或者**直接点选那件装备**，命令栏（检查器底部那排按钮）里有「维修」按钮，点一下即挂标记；
     已标记的装备同一位置变成「取消维修」。
5. 有「修补」工作的小人会依次搬起装备 → **摆到修补台台面上** → 对着台面工作
   （小人身体做前后锉磨晃动 ±7.5° + 自制的金属屑飞溅 + 自制锉磨工作音 + 物品上的进度条）
   → 按缺失耐久消耗修补剂并把它修满，
   修好时响一声金属扣合，装备放回台旁地上（不会自动回仓库，台面随即空出来给下一件）。

修满一次大约需要 3000 工作单位，按缺失耐久折算：**每缺失 10% 耐久 ≈ 1 个修补剂、300 工作**。
工作速度吃「综合劳动速度」（GeneralLaborSpeed），并受手工技能经验（每 tick +0.1 Crafting）。
中途被打断不丢进度：进度按物品记录，回来接着修。

## 提示与 Alert

修补剂不够/没有台时，有四个互相独立的提示，不用打开任何面板就能看见：

- **红色警报（Alert，High 优先级）**：右侧警报列表靠上的位置出现「有装备等待修补」，出现时会响一声提示音；点击可跳到相关物品。原版 Medium 级警报排在列表末尾又不响铃，容易完全没注意到，所以这里用 High。
- **地图上的缺料图标**：修补剂用光时，台子上会像原版燃料工作台那样浮起**脉动的「缺料」图标**（修补剂图标 + 红色禁止标记），隔着屏幕也能看见。
- **燃料条 Gizmo**：选中修补台，检查器里就有修补剂（repair kits）余量条，一眼看到剩多少。
- **检视面板红字**：修补剂为 0 时，修补台的检视文字会多一行红字「修补剂不足，请先装入更多修补剂再修理。」

右键菜单里的「维修装备」「强制维修」都会提前告诉你这件东西要几个修补剂（如「需要 4 个修补剂」），
装备还穿在身上 / 耐久是满的时候，相应菜单项会变灰并说明原因。
「强制维修」变灰的常见原因：物品被别人占用、没有装了足够修补剂的修补台、
或这名小人的「修补」工作类型没启用（工作面板里优先级为 0）。

## 已知限制（v1）

- **只修地上的装备**。穿在身上 / 拿在手里的装备没有「脱下」命令，无法标记；请先让小人丢下。
- 修完**不自动归仓**，物品留在修补台旁。
- 不修补建筑（建筑请用原版「修理」工作）。
- 不支持堆叠物品：堆叠数 > 1 的装备无法标记（武器/护甲正常情况都是单件）。
- 修补剂图标固定为单张（Graphic_Single），堆到 1 个还是 50 个都长一样。
- 未做品质、耐久上限的额外加成：修满即 100%，品质 / 材质 / 词条保持原样。

## 兼容性

- 只做 XML Def + 1 个补丁（往原版「命令」分类追加设计器）+ 独立 DLL，不改原版 Def 数值。
- 与「修理建筑」的原版系统、各类工作类型 mod 不冲突；新增工作类型「修补」默认激活，可在工作优先级里调整。
- 建筑按原版工作台谱系派生（`BenchBase`），放置预览的工作格显示原版座椅图形；不挂账单页、不耗电。
- 与 **Yayo's Animation** 共存：原版本身没有「工作动画」（工作台工作是站着放特效），
  大家看到的工作动作来自 Yayo's Animation 按 JobDef 名硬编码的白名单；本 mod 的 JobDef 不在它的名单里，
  所以本 mod 自带一个 Root 角度动画自己动。Yayo 检测到小人有动画会让位（不叠加），两边不打架。
- 存档：新增自定义 MapComponent 记录修理进度；**中途移除本 mod 未验证**（建议先修完再移除）。

## 安装

把 `Repair Bench` 文件夹放进 `RimWorld/Mods/`，在游戏内启用。需要 RimWorld 1.7。

## 开发

```powershell
# 编译（注意：需要 .NET 10 SDK，系统只装了 9 时用用户目录的 dotnet）
& "$env:USERPROFILE\.dotnet\dotnet.exe" build .\Source\RepairBench\RepairBench.csproj -c Release

# 静态自检（23 项契约：Def 字段、命名、语言、贴图/音频路径、特效引用、工作动画、装备命令栏按钮、右键强制维修、音量上限、DLL 元数据、部署白名单等）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\verify.ps1 -Strict

# 部署到游戏目录（会先结束正在运行的 RimWorld）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\deploy.ps1

# 打包发布版（不含 Source）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\make-release.ps1
```

数值都在 XML 里（`Defs/ThingDefs_Buildings/RepairBench_Bench.xml` 的 modExtension：
`ticksForFullRepair` / `kitsForFullRepair`），改完不需要重新编译。

## 致谢与参考

同期类似的装备修理实现（思路参考，非代码来源）：NanoRepairTech、MendAndRecycle、Repairable Gear。
美术：扁平矢量风自绘（Pillow 程序化绘制），对齐原版建筑贴图的描边 / 三阶平涂 / 俯视 2.5D 规范。
特效与音效同样是自制的：金属屑粒子（3 张 16×16 变体）与两段 wav（锉磨循环、修好扣合）都由本 mod 自带，
不引用原版 Assets.zip 的音频，也不借用原版「修理」的焊花特效。
音量对齐原版工作音（`volumeRange` 10~12，原版 Recipe_Smith 12 / Recipe_Tailor 10；收尾音 14~18），
`distRange` 10~50 与原版一致，所以站在别的台子旁边听起来是同一档音量。
